# Project 1: Clean and describe

Follow the Project 1 brief in the Data Insight curriculum (`stages/stage-1/project-1-clean-and-describe.md`).

1. Put your raw data file in `data/raw/`, exactly as downloaded.
2. Open `project.ipynb` in Colab. In Colab's Files panel, create the folders `data/raw` and `data/clean`, and upload the same raw file into `data/raw`.
3. Replace every TODO, run all cells, and save back with File, Save a copy in GitHub.
4. Check the Actions tab. A green check means every automatic check passed.
