# Stage 0: Tools check

Follow the steps in module 0.1 of the Data Insight curriculum:

1. On a new branch, edit `about-me.md`, open a pull request into `main`, and merge it.
2. Open `environment-check.ipynb` in Colab, run every cell, and save it back to this repository with File, Save a copy in GitHub.
3. Check the Actions tab. A green check means every automatic check passed.
