# Project 2: Compare two groups

Follow the Project 2 brief in the Data Insight curriculum (`stages/stage-1/project-2-compare-two-groups.md`).

1. Put your data file in `data/`.
2. Open `project.ipynb` in Colab. In Colab's Files panel, create a `data` folder and upload the same file.
3. Replace every TODO and `...`, run all cells, and save back with File, Save a copy in GitHub.
4. Check the Actions tab. A green check means every automatic check passed.
