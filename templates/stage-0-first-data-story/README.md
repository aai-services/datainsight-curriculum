# Stage 0: First data story

Follow module 0.2 of the Data Insight curriculum:

1. Download a public CSV about your community and add it to the `data` folder (Add file, Upload files).
2. Open `story.ipynb` in Colab. In Colab's Files panel, create a `data` folder and upload the same CSV, so the notebook can read it.
3. Replace every TODO, run all cells, and save back with File, Save a copy in GitHub.
4. Check the Actions tab. A green check means every automatic check passed.
