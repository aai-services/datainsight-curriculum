# Brand images

The notebooks show a Data Insight banner at the top and a small mark in the footer. The images are drawn by code, so they can be rebuilt or restyled at any time:

```bash
python scripts/build_brand_assets.py
```

This writes `banner-stage-0.png` to `banner-stage-3.png` and `mark.png` to this folder. Commit them so the notebooks can display them.

The colors match the website: navy `#14213D`, with the five topic colors used on the home page chart. The typeface is Public Sans (SIL Open Font License).
