# AI tutor cards: Stage 0

In Stage 0, use AI tools as a tutor, not a writer. Copy these prompts and fill in the brackets.

## When you are stuck on an error

> I am learning Python in a data science course and I am not allowed to have code written for me. Here is my error message: [paste the error]. Explain what it means in simple terms, and ask me one question that helps me find the problem myself. Do not give me corrected code.

## When a concept is unclear

> I think [Git commit / a pull request / a CSV file] means [your own explanation]. Tell me what is right, what is wrong, and what is missing. Keep it short.

## When you are looking for data

> I want to answer this question about [your country or region]: [your question]. Suggest three public data sources that might have suitable data, and explain what to check about each source's license. Do not analyse the data for me.

## To check your understanding

> Ask me three short questions about [Markdown / Git branches / loading a CSV with pandas], one at a time. Wait for my answer before giving feedback.

Always check what an AI tool tells you. It can be wrong, and it can invent datasets or links that do not exist.
