# Data Insight Curriculum

Open curriculum for the [Data Insight](https://datainsightonline.com) program: free, project-based data science training. Data Insight is an initiative of [aai-services](https://github.com/aai-services).

## Contents

- [`curriculum-map.md`](curriculum-map.md): program structure, stages, modules, projects, and weekly rhythm
- [`policies/ai-use.md`](policies/ai-use.md): how fellows may use AI tools at each stage
- [`rubrics/project-rubric.md`](rubrics/project-rubric.md): the rubric used for every project and capstone

Module notebooks, project briefs, and starter repositories will be added stage by stage.
